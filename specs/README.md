# Especificações e Guias de Estudo — BunDB

Este diretório contém a base conceitual, os modelos de domínio e os desafios do projeto **BunDB**.
Ele foi desenhado para servir de bússola para o aprendizado prático em **Bun**, manipulação de arquivos (**I/O / fs**) e **regras de negócio financeiras**.
