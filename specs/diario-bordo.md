# Diário de Bordo & Lições Aprendidas — BunDB

Este arquivo é o espaço reservado para registrar os aprendizados obtidos durante a jornada de desenvolvimento do BunDB.

---

## Como usar este diário?
Sempre que você:
- Descobrir uma peculiaridade do runtime **Bun** (ex.: como o `Bun.file` se comporta se o arquivo não existe);
- Enfrentar um bug de concorrência ou I/O e encontrar uma solução;
- Descobrir uma armadilha em regras financeiras (ex.: arredondamento de centavos, cálculo de juros compostos vs simples);
- Tomar uma decisão arquitetural consciente (trade-off escolhido);

Anote aqui em formato de tópicos breves!
